---

## 1. 项目概述

### 1.1 产品定位

桌面 TODO 是一款面向个人用户的轻量桌面专注工具，用于完成以下闭环：

**开始专注 → 倒计时 → 记录产出 → 休息 → 下一段专注**

产品以 Windows 桌面常驻工具为主要使用场景，强调快速进入专注、低操作成本、记录可回看和结果可汇总。

### 1.2 本版目标

本版以 Page 4 的青绿色暗黑设计为唯一视觉基准，重点实现：

1. 建立更适合长期桌面使用的暗色效率工具体验。
2. 以 `#14B8A6` 作为统一主色，形成清晰的品牌识别。
3. 强化计时、记录、统计、历史检索之间的信息层级。
4. 保持现有核心功能闭环，不引入复杂账号、云同步或任务管理能力。

### 1.3 非目标

以下内容不属于本版设计范围：

- 用户账号、登录、云同步。
- 多人协作、团队空间。
- 任务分级、项目管理、看板。
- 移动端适配。
- 原型中未出现的额外业务入口。
- 手动添加记录与编辑记录能力保留，并纳入本版功能验收；入口作为次级操作，不影响原型的主动作层级。

## 2. 目标用户与核心场景

### 2.1 目标用户

- 需要长时间在电脑前工作的个人用户。
- 希望记录每个工作段产出，但不想使用复杂项目管理工具的用户。
- 偏好暗色界面、数据反馈明确、操作路径短的效率工具用户。

### 2.2 核心场景

1. 用户打开应用，选择或确认专注时长后开始工作。
2. 专注结束后，填写这段时间完成的内容并进入休息。
3. 一天结束时查看今日专注段数、总分钟数和记录。
4. 通过关键词或日期范围查找历史专注记录。
5. 将当天记录汇总后发送到绑定邮箱。
6. 通过桌面挂件快速确认剩余时间和当前状态。

## 3. 信息架构

本版包含 6 个设计画板：

| 画板 | 核心任务 |
|---|---|
| 专注 | 开始、暂停、结束专注，并查看当前进度 |
| 专注记录 | 填写当前专注段的产出与标签 |
| 今日 | 查看今日总量、近期记录并发送邮件 |
| 设置 | 配置邮箱、计时节奏和挂件显示 |
| 历史 | 搜索、筛选和回看历史记录 |
| 桌面挂件 | 查看挂件运行、暂停和休息状态 |

主导航固定为 4 项：

**专注 / 今日 / 历史 / 设置**

专注记录为流程页，不进入底部主导航。桌面挂件为独立窗口，不进入主导航。

## 4. 视觉与交互基准

### 4.1 画布与布局

- 主窗口尺寸：`420 × 780 px`。
- 主画板采用垂直单列布局。
- 内容安全边距：左右 `24 px`，上下 `24 px`。
- 页面主间距：`14–16 px`。
- 卡片间距：`8–12 px`。
- 实际挂件尺寸：`170 × 32 px`。
- 设计稿中的挂件使用 `340 × 64 px` 进行 2 倍预览。

### 4.2 色彩规范

| 用途 | 色值 |
|---|---|
| 页面背景 | `#0B0C0F` |
| 主卡片 | `#15171C` |
| 次级面板 | `#1A1D23` |
| 主色 | `#14B8A6` |
| 主色浅文字 | `#5EEAD4` |
| 主色深底 | `#102A28` |
| 一级文字 | `#F5F7FA` |
| 二级文字 | `#A3AAB5` |
| 三级文字 | `#7A8290` |
| 分隔与轨道 | `#2A2E36` |
| 成功状态 | `#34D399` |
| 提醒状态 | `#FBBF24` |
| 危险/错误状态 | `#F87171` |

使用规则：

- 主色用于主操作、选中态、进度、品牌标记、开关开启态和关键强调。
- 主色按钮使用深色文字，避免白字对比不足。
- 绿色成功态与主色同时出现时，应通过位置、标签或图形承担区分作用。
- 不使用高饱和渐变、硬投影、彩色发光和高亮描边。

### 4.3 字体

- 大数字、英文标题：`Inter Tight`。
- 中文正文、中文标签：`Noto Sans SC`。
- 正文最小字号不低于 `9 px`；关键信息正文不低于 `10 px`。
- 计时数字使用等宽数字表现，确保秒级变化不引起横向跳动。

### 4.4 组件规范

- 卡片圆角：`8–12 px`。
- 输入框圆角：`8 px`。
- 按钮圆角：`8 px`。
- 胶囊标签圆角：`14 px` 或全圆角。
- 普通卡片使用轻阴影或纯色层级，不使用硬边投影。
- 可交互元素有效点击区域不小于 `44 × 44 px`。

### 4.5 窗口操作

- 应用使用无边框窗口，所有页面顶部栏均可拖动移动窗口。
- 按钮、输入框和其他可交互控件区域不得触发窗口拖动。
- 每个页面顶部栏均提供最小化按钮。
- 点击最小化后主窗口隐藏到任务栏或托盘，计时器和挂件继续运行。
- 主窗口保持固定尺寸，不提供最大化操作。

## 5. 功能需求

### 5.1 专注主屏

#### FR-FOCUS-01 顶部品牌区

- 左侧展示主色品牌标记和“专注”标题。
- 标题下展示“桌面 TODO · 专注计时”。
- 右侧固定展示快捷键提示 `Ctrl + K`，不使用 `⌘ K`。
- 快捷键用于快速聚焦开始/暂停主操作。

#### FR-FOCUS-02 计时状态

- 页面必须明确显示当前状态：专注中、已暂停、休息中、记录中。
- 必须显示当前轮次，例如 `01 / 04`。
- 默认工作段时长为 25 分钟。
- 默认轮次数为 4 段。

#### FR-FOCUS-03 倒计时

- 主计时采用 `MM:SS` 格式。
- 默认显示 `25:00`。
- 计时运行时实时刷新。
- 暂停时画面保持静止，状态文案和按钮同步变化。
- 工作段和休息段共用同一计时状态。

#### FR-FOCUS-04 进度反馈

- 展示当前段的线性进度条。
- 进度从 `0%` 增长至 `100%`。
- 两端显示已用时间和目标时间。
- 状态切换后，进度和剩余时间必须同步更新。

#### FR-FOCUS-05 今日指标

计时卡内固定展示三项指标：

| 指标 | 含义 |
|---|---|
| 工作段 | 今日已完成工作段数 |
| 专注 | 今日累计专注分钟数 |
| Streak | 连续使用天数 |

数值必须来自本地持久化数据，不允许使用硬编码占位值。

#### FR-FOCUS-06 时长预设

- 提供 `25 分 / 30 分 / 45 分 / 60 分` 四个预设。
- 仅空闲状态允许选择预设。
- 点击预设只更新计划时长和计时显示，不自动开始计时。
- 当前时长对应的预设使用主色填充和深色文字。
- 专注运行、专注暂停、休息运行、休息暂停和记录状态下，所有预设必须禁用，并显示“结束当前段后可更改时长”的提示。
- 运行中点击或通过其他入口请求切换预设，不得改变当前段的剩余时间、开始时间和进度。

#### FR-FOCUS-07 计时操作

- 页面只保留一套开始/暂停/继续主操作，不重复放置暂停按钮。
- 主操作按钮：开始专注 / 暂停计时 / 继续专注；休息状态显示暂停休息 / 继续休息。
- 次操作按钮：空闲时禁用；专注运行或暂停时显示“结束”；休息运行或暂停时显示“跳过”。
- 点击“结束”必须二次确认，提示当前已进行时间和“本段不会写入记录”。
- 取消确认后保持原计时状态继续运行或暂停。
- 确认结束后丢弃当前工作段并进入休息。
- 跳过休息前必须二次确认，确认后立即进入下一工作段。
- 每次开始计时都必须为当前段生成固定时长快照；运行过程中设置页修改的时长只影响下一段。
- 主进程必须拒绝非空闲状态下的重复开始、时长切换和状态覆盖请求。

#### FR-FOCUS-08 底部导航

- 固定展示“专注 / 今日 / 历史 / 设置”。
- 当前页面使用主色深底和浅主色文字。
- 切换页面时不得重置正在运行的计时器。

### 5.2 专注记录页

#### FR-NOTES-01 会话摘要

页面顶部展示当前专注会话的以下信息：

- 开始时间。
- 结束时间。
- 实际时长。

时间与时长只读，由计时器状态提供。

#### FR-NOTES-02 记录输入

- 页面标题使用“专注记录”。
- 问题文案为 `What did you get done?`。
- 输入区支持多行自由文本。
- 输入内容上限为 500 个字符。
- 右侧展示实时字符计数，例如 `132 / 500`。
- 内容为空时禁止保存，并给出明确提示。

#### FR-NOTES-03 草稿

- 用户输入后自动保存草稿。
- 页面显示最后一次自动保存时间。
- 保存成功后清空当前草稿。
- 关闭页面后再次进入时，应恢复未提交草稿。

#### FR-NOTES-04 快捷标签

提供以下 4 个快捷标签：

- 写代码
- 开会
- 学习
- 摸鱼

选中标签使用主色浅底和浅主色文字。标签为单选；再次点击已选标签可取消选择。

#### FR-NOTES-05 页面操作

- 主动作：保存并开始休息。
- 次动作：放弃当前记录。
- 放弃后不写入记录，并按计时规则进入休息。
- 保存成功后进入休息倒计时，并返回专注主屏。

#### FR-NOTES-06 手动添加记录

- 保留现有手动添加记录能力。
- 入口位于专注主屏和今日页，以次级 `+` 操作呈现，不替代开始专注和发送邮件等主动作。
- 手动添加支持选择工作记录或休息记录、设置时长、填写内容并选择标签。
- 手动添加只写入数据库，不改变当前计时器状态。
- 保存成功后返回来源页面，并刷新今日与历史数据。

#### FR-NOTES-07 编辑记录

- 保留现有编辑记录能力。
- 点击今日或历史记录中的条目进入编辑状态。
- 可编辑内容、标签和有效时长，不可直接改变记录类型。
- 保存后立即更新记录数据和相关统计。
- 取消编辑时不修改原记录。

### 5.3 今日页

#### FR-TODAY-01 页面标题

- 标题：“今日”。
- 展示当前中文日期和星期。
- 右上角展示日期胶囊，例如“10 月 27 日”。

#### FR-TODAY-02 今日总览

必须展示：

- 今日累计专注分钟数，作为最大数字。
- 今日工作段数。
- 今日休息次数。

数据按本地日期计算，不按 UTC 日期截断。

#### FR-TODAY-03 近期记录

- 展示今日记录列表，默认按开始时间倒序。
- 每条记录展示：
  - 开始时间。
  - 记录正文。
  - 标签。
  - 实际专注分钟数。
  - 与标签对应的状态色条。
- 列表为空时展示明确空状态，不显示空白卡片。

#### FR-TODAY-04 邮件汇总

- 底部展示深色邮件卡片。
- 文案包含记录条数和累计分钟数。
- 点击发送后展示发送中状态，防止重复点击。
- 发送成功显示成功提示。
- 发送失败显示可复制的错误信息。
- 未配置邮箱或授权码时，应提示用户前往设置完善配置。

### 5.4 设置页

#### FR-SETTINGS-01 页面结构

页面按顺序包含：

1. 顶部标题和版本信息。
2. 邮件发送配置入口。
3. 计时节奏配置。
4. 桌面挂件显示配置。
5. 保存按钮。
6. 底部主导航。

#### FR-SETTINGS-02 邮箱配置

- 展示已配置邮箱地址和连接状态。
- 点击“编辑”后，在设置页内展开邮箱信息编辑区域，不使用独立弹层或独立页面。
- 需要支持 QQ 邮箱和 SMTP 授权码输入。
- 授权码不得明文展示；编辑时使用密码输入样式。
- 邮箱与授权码保存在本地 SQLite。
- 展开编辑区域后，应保持与页面其他配置的视觉层级一致，不遮挡主导航。

#### FR-SETTINGS-03 计时节奏

以 `2 × 2` 卡片网格展示：

- 专注时长：工作段时长，默认 25 分钟。
- 短休息：短休时长，默认 5 分钟。
- 长休息：长休时长，默认 15 分钟。
- 长休频率：默认每 4 段。

每项均必须提供清晰可见的减号与加号控件，四项操作方式保持一致。

每项均可调整，且必须受以下范围限制：

| 配置 | 范围 |
|---|---|
| 工作段 | 1–120 分钟 |
| 短休 | 1–30 分钟 |
| 长休 | 1–60 分钟 |
| 长休频率 | 1–8 段 |

#### FR-SETTINGS-04 挂件配置

提供两个开关：

- Show remaining time：显示剩余时间。
- Show playback controls：显示开始/暂停控制。

开关开启时使用主色，关闭时使用中性深灰。默认仅保留进度条和状态点。

#### FR-SETTINGS-05 每日自动发送

- 邮箱配置区域提供“每日自动发送”开关和时间选择器。
- 自动发送默认关闭；用户开启后必须选择发送时间，格式为 `HH:mm`。
- 设置页展示当前是否开启、发送时间以及下次计划发送时间。
- 自动发送使用系统本地时区，并按自然日计算汇总范围。
- 今日页的手动“发送”按钮继续保留，用于即时发送和手动补发。
- 自动发送与手动发送分别记录状态；当天手动发送成功不阻止定时任务再次自动发送。

#### FR-SETTINGS-06 保存设置

- 点击“保存设置”后保存所有修改。
- 保存期间按钮进入禁用或加载状态。
- 保存成功显示确认提示。
- 保存失败保留当前输入，并展示可理解的错误信息。

### 5.5 全部记录页

#### FR-HISTORY-01 页面标题

- 标题：“历史”。
- 副标题：“每一段专注，都在这里。”。
- 右上角展示当前筛选结果总数。

#### FR-HISTORY-02 搜索

- 搜索框支持按记录正文和标签搜索。
- 输入后实时过滤结果。
- 搜索无结果时展示明确空状态。
- 提供 `/` 快捷键聚焦搜索框。

#### FR-HISTORY-03 日期筛选

提供四个筛选项：

- 今天
- 昨天
- 本周
- 全部

当前筛选项使用白色或高对比选中样式。一次只能启用一个筛选项。

#### FR-HISTORY-04 分组列表

- 记录按日期倒序分组。
- 分组标题包含日期和该组记录数。
- 每条记录展示开始时间、正文、标签和专注分钟数。
- 无记录时，不展示空分组。

#### FR-HISTORY-05 底部统计

- 深色统计条展示当前筛选结果的记录总数和累计专注分钟数。
- 搜索或筛选变化后，统计数据必须同步更新。

### 5.6 桌面挂件

#### FR-WIDGET-01 基本规格

- 实际窗口尺寸：`170 × 32 px`。
- 无边框、透明背景、常驻置顶。
- 默认位于桌面右上角。
- 可通过拖动改变位置。
- 双击展开主窗口。

#### FR-WIDGET-02 运行状态

挂件展示：

- 状态点。
- 播放/暂停入口。
- 进度条。
- 剩余时间。

状态颜色规则：

| 状态 | 主色 |
|---|---|
| 专注中 | `#14B8A6` |
| 已暂停 | `#FBBF24` |
| 休息中 | `#34D399` |
| 记录中 | `#5EEAD4` |

- 剩余时间和播放按钮根据设置页开关决定是否显示。
- 默认隐藏时间和播放按钮，只保留进度条和状态点。
- 设置保存后，挂件即时同步显示状态。

#### FR-WIDGET-04 主窗口同步

- 挂件与主窗口共享同一计时器实例。
- 任意一端开始、暂停、跳过或结束，另一端必须同步更新。
- 页面切换、窗口隐藏或最小化不得中断计时。

## 6. 计时状态与业务规则

### 6.1 状态定义

| 状态 | 说明 |
|---|---|
| IDLE | 空闲，可调整时长 |
| FOCUS_RUNNING | 工作段运行中 |
| FOCUS_PAUSED | 工作段暂停 |
| RECORDING | 工作段结束，等待填写记录 |
| BREAK_RUNNING | 休息运行中 |
| BREAK_PAUSED | 休息暂停 |

### 6.2 状态规则

1. 工作段暂停后，剩余时间冻结。
2. 工作段恢复后，从冻结值继续。
3. 工作段正常结束后进入记录页。
4. 正常保存记录后进入休息倒计时。
5. 放弃记录时不写入数据库，但必须继续进入休息。
6. 休息结束后进入下一工作段。
7. 每满 N 个工作段进入一次长休。
8. 主屏、记录页和挂件必须使用同一计时状态源。

### 6.3 防重复操作

- 开始、暂停、结束、保存、发送邮件均需防止重复提交。
- 计时结束和记录保存之间必须保持明确的 `RECORDING` 状态。
- 记录页未完成时，不允许通过底部导航绕过记录流程。

### 6.4 每日自动发送规则

1. 自动发送默认关闭，由用户在设置页开启并设置发送时间。
2. 应用在发送时间处于运行状态时，自动生成当天记录汇总并发送。
3. 当天没有工作记录时，跳过发送，不生成空汇总邮件。
4. 应用在发送时间未运行时，下次启动后补发上一自然日尚未成功自动发送的汇总。
5. 上一自然日没有工作记录时，同样跳过发送。
6. 自动发送失败时，记录失败原因并提示用户；本次运行不自动重试，下次启动时再次补发。
7. 每个自然日最多自动发送一次，手动发送不计入自动发送次数。
8. 当天手动发送成功后，定时任务仍按计划再自动发送一次。
9. 自动发送必须使用与手动发送相同的汇总格式、邮箱配置和 SMTP 规则。

## 7. 数据需求

### 7.1 sessions

每条工作记录至少包含：

- `id`
- `started_at`
- `ended_at`
- `duration_min`
- `content`
- `tag`
- `type`

规则：

- 日期按本地时区计算。
- 放弃的工作段不写入数据库。
- 历史页只展示工作记录。
- 今日页统计工作段数量和累计分钟数。

### 7.2 settings

需要保存以下键：

- `qq_email`
- `qq_auth_code`
- `work_min`
- `short_break_min`
- `long_break_min`
- `long_break_every`
- `widget_show_time`
- `widget_show_play`
- `widget_top`
- `daily_mail_enabled`：每日自动发送开关，`1` 为开启，`0` 为关闭，默认 `0`
- `daily_mail_time`：每日自动发送时间，格式为 `HH:mm`
- `daily_mail_last_success_date`：最近一次自动发送成功的自然日
- `daily_mail_last_skip_date`：最近一次因无记录而跳过的自然日
- `daily_mail_last_error`：最近一次自动发送失败原因

### 7.3 数据同步

- 记录保存后，今日与历史记录重新查询并刷新。
- 设置保存后，专注主屏、桌面挂件和自动发送计划同步最新配置。
- 搜索与筛选只改变视图结果，不修改原始数据。
- 自动发送补齐后，今日、历史记录和发送状态同步刷新。

## 8. 异常与空状态

必须覆盖以下状态：

| 场景 | 要求 |
|---|---|
| 今日无记录 | 展示“今天还没有专注记录”空状态 |
| 历史搜索无结果 | 展示明确无结果说明，并允许清空搜索 |
| 未配置邮箱 | 提示先完成邮箱配置 |
| 邮件发送失败 | 展示错误原因，不清空记录 |
| 草稿为空 | 禁止保存，并提示补充内容 |
| 授权码错误 | 保留输入，展示可操作的失败提示 |
| 计时器暂停 | 进度、按钮和挂件状态同步冻结 |
| 应用关闭到托盘 | 主窗口隐藏但计时继续运行 |
| 自动发送时无记录 | 跳过发送，不生成空邮件 |
| 自动发送失败 | 记录失败原因并提示，下次启动补发 |
| 应用错过发送时间 | 下次启动补发上一自然日汇总 |
| 邮箱未配置 | 自动发送不执行，提示先完成配置 |

## 9. 非功能需求

### 9.1 性能

- 主窗口冷启动后应尽快显示内容，不出现明显白屏。
- 倒计时刷新不得造成布局跳动。
- 搜索与筛选在本地数据量正常范围内应即时反馈。
- 计时器使用绝对时间计算，避免长时间运行产生累计漂移。

### 9.2 可用性

- 所有主操作均有明确文字标签，不只依赖图标。
- 键盘焦点、禁用态和错误态可辨识。
- 文本在暗色背景上满足清晰可读要求。
- 界面可见文案统一使用简体中文；“桌面 TODO”、版本号、邮箱地址、SMTP 和快捷键 `Ctrl+K` 可保留拉丁字符。
- 支持 Windows 常见缩放比例，不出现裁切。

### 9.3 兼容性与持久化

- 适配 Windows 桌面环境。
- 记录和设置保存在本地 SQLite。
- 重启应用后记录和设置不丢失。
- 授权码仅在本地使用，不上传到第三方服务。

### 9.4 设计一致性

- 六个画板使用同一套颜色、字体、圆角、阴影和状态规范。
- 页面标题、导航位置、按钮层级和反馈方式保持一致。
- 原型中的英文界面标签与中文业务内容可以共存，但同一语义不得出现多种写法。
