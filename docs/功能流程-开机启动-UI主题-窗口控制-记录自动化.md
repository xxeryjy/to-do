# 桌面 TODO 功能流程设计

> 状态：v0.6.0 已实现
> 日期：2026-10-30
> 范围：开机启动、UI 主题、窗口控制、任务规划、数据统计、自动化、外部同步边界

## 1. 已确认决策

| 需求 | 当前实现 |
| --- | --- |
| 开机启动 | 设置页提供开关，默认关闭，按当前可执行文件路径写入 |
| UI 风格 | 暗黑青绿、糖果风格、浅色工作台三种主题，即时切换并持久化 |
| 默认风格 | 暗黑青绿 |
| 窗口按钮 | 所有页面提供最小化与关闭按钮 |
| 关闭行为 | 隐藏到系统托盘，不结束进程，计时和通知继续 |
| 任务入口 | 并入“今日”，不增加第五个导航项 |
| 任务模型 | 扁平任务，可选项目与预估时长 |
| 数据统计 | 预估与实际偏差、本月项目投入 |
| 自动化 | 记录草稿、标签映射、专注场景、每周总结、快捷键 |

## 2. 开机启动

- 默认关闭。
- 打开后写入当前用户登录启动项，关闭后移除。
- 当前按 `process.execPath` 写入；便携版移动文件位置后需要重新开启。
- 启动时自动同步设置与操作系统状态。

验收标准：设置可持久化；关闭后不影响当前运行；重新登录后按开关状态启动或停止。

## 3. UI 风格

可选风格：

- 暗黑青绿
- 糖果风格
- 浅色工作台

规则：

- 切换即时生效，不需要重启。
- 保存后下次启动恢复。
- 覆盖主窗口、记录页、今日、历史、设置、Toast、确认弹窗、更新弹窗和桌面挂件。
- 浅色主题使用左侧竖向导航；其他主题使用底部导航。
- 系统通知保持 Windows 原生样式。

验收标准：三种主题无旧主题残留颜色，不中断计时，不丢失输入，选中/禁用/错误状态清晰。

## 4. 窗口控制

- 最小化：进入任务栏，应用继续运行。
- 关闭：隐藏到系统托盘，应用继续运行。
- 真正退出：仅通过托盘菜单“退出”。
- 隐藏状态下计时、通知和提示音正常运行。

验收标准：点击关闭后进程不退出；托盘和通知可以恢复主窗口。

## 5. 基础任务规划

- “今日”页展示未完成任务和当天完成的任务。
- 新增任务默认只需要名称。
- 可选填写项目与预估时长。
- 从任务直接开始专注，首页显示当前任务。
- 专注记录关联 `task_id`。
- 任务显示累计专注分钟数。
- 勾选完成，再次点击可重新打开。
- 未完成任务自动保留到后续日期。

验收标准：新增任务 → 开始专注 → 保存记录 → 累计时间 → 完成，全流程可闭环。

## 6. 进阶规划与数据统计

### 拖拽排期

- 今日页打开“安排一天”。
- 时间轴范围为 09:00–18:00。
- 任务默认按预估时长排期；未设置时使用 60 分钟。
- 任务可重新拖到其他时间段。

### 预估与实际偏差

- 仅统计设置了预估时长且有关联专注记录的任务。
- 展示本月预估总时长、实际总时长和任务级偏差。

### 项目投入

- 按任务项目汇总本月专注时间。
- 未设置项目的任务归入“未归类项目”。
- 仓库统计需要 GitHub 同步接入后提供。

验收标准：排期时间写入数据库；重新打开仍保留；洞察数据与关联任务记录一致。

## 7. 自动化

### 已实现

- 专注结束自动生成可编辑记录草稿。
- 根据任务标题推断“写代码 / 开会 / 学习”标签。
- 记录页自动带出关联任务和项目。
- 每周总结邮件：最近 7 天、可选星期与时间。
- 自动化快捷键：
  - `Ctrl+Shift+B`：延长休息
  - `Ctrl+Shift+Enter`：保存记录
  - `Ctrl+Shift+N`：开始下一轮或保存记录
- 全局快捷键注册失败时保留应用内快捷键。
- 专注场景可启动用户配置的本地工作软件。
- Windows 勿扰模式不可自动控制时，显示明确降级提示。

### 隐私和执行原则

- 草稿只写入用户正在编辑的记录表单，不静默保存。
- 不读取键盘输入、剪贴板、屏幕内容或窗口标题。
- 自动启动软件只使用用户提供的本地路径。
- 邮件发送继续使用用户已配置的 QQ SMTP。

验收标准：自动草稿使用实际时长；手动修改优先于自动标签；关闭自动化后不再执行对应动作；失败时有可见反馈。

## 8. 外部工具同步边界

设置页提供以下适配入口：

- GitHub
- Jira
- Notion
- Todoist
- 日历

当前状态为“未配置”。真实同步需要各平台 OAuth 应用、回调地址和最小权限范围，因此不在未授权情况下伪造连接或上传数据。

## 9. 暂不实施

- 不接入电脑活动监控、键盘记录、录屏或剪贴板。
- 不默认接入第三方 AI。
- 不自动保存无用户确认的记录。
- 不在没有 OAuth 配置时连接外部平台。
- 不修改 Windows 注册表强制关闭全部系统通知。
