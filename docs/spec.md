## 1. 产品核心循环

```
开始工作段(默认25min) → 倒计时 → 时间到 → 弹出「记录填写」
→ 保存 → 进入休息(短休5min) → 休息完 → 下一工作段
                                  │
                        每满 4 个工作段 → 长休(15min)
```

- 休息类型：短休 5 分钟、长休 15 分钟，每 4 段一个长休（均可设置）。
- 记录内容为自由文本，自动带起止时间，可选快捷标签。
- 无账号、无云同步、无任务分级。

## 2. 六屏功能规格

### 2.1 计时主屏
| 要素 | 行为 |
|---|---|
| 大数字倒计时 | 显示剩余 `MM:SS`，实时刷新（主进程推送） |
| 状态 | 工作中 / 休息中 / 空闲，颜色随状态切换 |
| 段数 | `第 N 段 / 共 4 段`（N 为本轮内第几个工作段） |
| 快速预设 | 25 / 30 / 45 / 60 分钟，点击立即设为工作段时长并可直接开始 |
| 开始 / 暂停 / 结束 | 见状态机 §3 |
| 进度条 | 线性，显示当前段已消耗比例 |
| 底部统计 | 今日已完成工作段数 |

### 2.2 进度条挂件（迷你窗）
| 要素 | 行为 |
|---|---|
| 形态 | 170×32 胶囊条，无边框窗口，常驻置顶（默认仅进度条+状态点，播放/时间按钮在设置里开） |
| 内容 | 播放/暂停按钮 + 渐变进度条 + 时间 + 状态点 |
| 置顶 | 默认 `alwaysOnTop`，可拖动 |
| 与主屏同步 | 同一计时器实例，主屏与挂件显示相同剩余时间 |
| 收起/展开 | 点击挂件可展开为主屏（或提供入口按钮） |

### 2.3 记录填写
| 要素 | 行为 |
|---|---|
| 触发 | 工作段倒计时结束自动弹出 |
| 起止时间 | 只读展示（开始时间 → 结束时间 + 时长） |
| 文本输入 | 自由文本，多行，自动保存草稿（见 §4 交互） |
| 快捷标签 | 写代码 / 开会 / 学习 / 摸鱼，点击填充到内容开头或作为 tag 字段 |
| 放弃 | 丢弃该段，**不写入 sessions 表**，直接进入休息 |
| 保存并休息 | 写入 sessions，进入休息倒计时 |

### 2.4 今日记录
| 要素 | 行为 |
|---|---|
| 统计概览 | 今日工作段数 / 总分钟 / 休息次数 |
| 记录列表 | 当日全部记录，按时间倒序，含标签 |
| 发送邮件 | 把当日记录汇总为文本，经 QQ SMTP 发到设置的邮箱 |

### 2.5 设置
| 要素 | 行为 |
|---|---|
| QQ 邮箱 + 授权码 | 明文存本地 SQLite（userData 下），仅本机使用 |
| 工作段时长 | 步进 ±1，范围 1–120 分钟 |
| 短休时长 | 步进 ±1，范围 1–30 分钟 |
| 长休时长 | 步进 ±1，范围 1–60 分钟 |
| 长休频率 | 每 N 段，范围 1–8 |
| 保存 | 写入 settings 表，即时生效 |

### 2.6 全部记录（查找页）
| 要素 | 行为 |
|---|---|
| 搜索 | 关键词匹配 content 或 tag，实时过滤 |
| 日期筛选 | 今天 / 昨天 / 本周 / 全部 |
| 分组 | 按日期分组，组头显示日期与条数 |
| 底部统计 | 当前筛选结果条数 + 总专注分钟 |

## 3. 计时状态机

```
IDLE ──开始──▶ FOCUS_RUNNING ──倒计时结束──▶ RECORDING
 ▲                │  ▲                          │保存
 │                │  │暂停                      ▼
 │                ▼  │                    BREAK_RUNNING ──结束──▶ FOCUS_RUNNING(下一段)
 │             FOCUS_PAUSED                        ▲
 │                │继续                             │暂停
 └──结束(丢弃)────┴──────────────────────────── BREAK_PAUSED ──继续──▶
```

| 状态 | 说明 |
|---|---|
| IDLE | 未开始，可设时长、快速预设 |
| FOCUS_RUNNING | 工作段计时中，显示剩余时间 |
| FOCUS_PAUSED | 工作段暂停，时间冻结 |
| RECORDING | 计时结束，等待填写记录（主屏被记录填写覆盖） |
| BREAK_RUNNING | 休息计时中（短休/长休） |
| BREAK_PAUSED | 休息暂停 |

规则：
- 工作段暂停 → 时间冻结，恢复后继续。
- 工作段**结束** → 时间清零，丢弃当前工作段，进入休息。
- 休息被「跳过」→ 立即进入下一工作段。
- 主屏与挂件共用同一状态实例（存主进程），渲染层只做展示。

## 4. 关键交互细节

1. **草稿**：记录填写页的文本在用户输入后防抖 500ms 写内存草稿；关闭记录页再进入时恢复，保存成功后清空。
2. **邮件格式**：纯文本，标题 `今日工作记录 YYYY-MM-DD`，正文按段列出 `[HH:MM-HH:MM] 标签 内容`，结尾附总分钟。
3. **发送成功/失败**：Toast 提示；失败（授权码错/断网）给出可复制错误信息。
4. **挂件拖动**：无边框窗口，监听 mousedown/move 调用主进程 `win.setPosition`。
5. **置顶开关**：设置中可关闭挂件置顶，默认开启。

## 5. 验收标准（MVP）

- [ ] Windows 双击可运行，主屏打开即见计时器
- [ ] 工作段倒计时 → 自动弹记录填写 → 保存 → 自动进休息，循环正确
- [ ] 每 4 段出现长休，短休/长休/频率可在设置改并即时生效
- [ ] 记录持久化到本地 SQLite，重启不丢
- [ ] 今日记录页显示当日汇总，可一键发 QQ 邮件（真实发送成功）
- [ ] 全部记录页可搜索、可按日期筛选
- [ ] 挂件常驻置顶、可拖动、与主屏时间同步
